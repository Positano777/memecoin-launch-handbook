# Contributing

Submit a specific correction with a primary source, checked date, affected route/network/tool version, and reproducible public evidence. Clearly distinguish observed behavior, documentation, and recommendations. Never submit secrets, real keypairs, or unverifiable financial/safety claims.

Before a pull request run `node --test test/*.test.mjs` and `node tools/check-handbook.mjs`. Update SOURCES.md when platform assumptions change. Keep commands explicitly devnet unless a carefully reviewed production workflow requires otherwise. Preserve the distinction between platform-created and self-managed tokens.
