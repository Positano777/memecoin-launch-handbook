# L - Launch through pump.fun

Use the platform's official entry point and read its current creation documentation. Review name, symbol, metadata URI, creator, quote asset, creator-fee settings, and any special modes exposed by the current flow. Choose deliberately; a default visible in an old screenshot may no longer be current.

Before submission, inspect the wallet request, funding requirement, initial purchase if any, destination programs, and slippage/amount limits. Afterward, record the mint, creation signature, actual creator/fee arrangement, and the canonical coin page. A saved off-chain page or unsigned preview is not an on-chain creation receipt.

The official creation interface documents create_v2 and optional settings whose meaning changes over time. Cashback creation is documented as deprecated; this handbook does not enable it or infer a fee arrangement from old examples. Fees, routing, and migration need live confirmation. Read these separate sources at launch time:

- [Creation instruction reference](https://github.com/pump-fun/pump-public-docs/blob/main/docs/instructions/COIN_CREATION.md)
- [Fee schedule](https://pump.fun/docs/fees)
- [Creator fee sharing](https://github.com/pump-fun/pump-public-docs/blob/main/docs/instructions/CREATOR_FEE_SHARING.md)

**Deliverable:** [a launch receipt](../templates/launch-receipt.md). No transaction is generated by this handbook.
