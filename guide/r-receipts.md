# R - Release a verifiable launch record

Publish a compact launch receipt that a reader can independently check. Include the network, mint, token program, creation signature, metadata location, initial supply, relevant authorities, creator purchase, fee destinations, and liquidity evidence. Link a dated snapshot of your disclosure page.

Distinguish an observed transaction from an interpretation. A same-slot buyer is not automatically an insider; a fee payer may be a service. If you use the community launch-evidence exporter, preserve its coverage fields and unresolved attribution. Missing data is a limitation, not a clean result.

Record tool versions and source revisions so another contributor can reproduce the inspection. Do not publish private provider URLs or raw support logs in a receipt. Hash a public artifact after checking it for secrets.

**Deliverable:** [launch receipt](../templates/launch-receipt.md) and [community evidence tooling](https://github.com/Positano777/pumpfun-community-tools).
